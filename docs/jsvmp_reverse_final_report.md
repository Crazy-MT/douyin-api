## 完全逆向 JSVMP 的瓶颈

### 技术难点

1. **VM 指令语义未知**
   - 26,280 条指令
   - 80+ 个不同 opcode
   - 每个 opcode 需要 1-4 小时逆向
   - 总工作量：80-320 小时

2. **变长编码规则复杂**
   - bb 长度：137-140 字节（动态）
   - 无法通过值匹配定位写入指令
   - 需要完整理解 VM 内存模型

3. **缺少专业工具**
   - IDA Pro / Ghidra：需要许可证
   - angr / Triton：需要深度学习成本
   - 手工分析：效率极低

4. **bdms.js 混淆严重**
   - 348KB 混淆代码
   - 变量名无意义（a, b, c, d...）
   - 控制流混淆
   - 无法直接插桩

### 已尝试的方法

1. ✅ 静态分析 trace（完成）
2. ✅ 差分分析多时间样本（完成）
3. ✅ 数学建模（失败，非线性）
4. ✅ 符号执行（需要 Z3，未安装）
5. ❌ 动态插桩（bdms.js 难以修改）
6. ❌ 专业逆向工具（无可用工具）
